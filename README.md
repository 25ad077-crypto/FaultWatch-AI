# FaultWatch AI — Predictive Maintenance System

An AI-powered predictive maintenance web application built using R, Shiny, and Random Forest machine learning.

## Features
- Predict potential machine failures using sensor readings.
- Analyze air temperature and process temperature.
- Monitor rotational speed, torque, and tool wear.
- Display predicted failure probability.
- Visualize machine failure risk using a chart.
- Interactive web dashboard built with R Shiny.

## Technologies Used
- R Programming
- RStudio
- Shiny
- Random Forest
- UCI AI4I 2020 Predictive Maintenance Dataset

## How to Run

1. Install R and RStudio.
2. Install the required packages:

   `install.packages(c("shiny", "randomForest"))`

3. Open `app.R` in RStudio.
4. Click **Run App**.

## Dataset
The application uses the AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository.

## Disclaimer
This is an educational machine learning project. Predictions are estimates and should not replace professional industrial inspection.
